Tolle server
============

This folder is the complete Tolle server – nothing else needs installing.

Set it up (asks a few questions, can install a background service):
    Linux / macOS:   sudo ./tolle-server setup
    Windows:         tolle-server.exe setup        (in an Administrator PowerShell)

Or just run it:
    ./tolle-server serve --port 8099 --host 0.0.0.0

Other commands:   ./tolle-server --help
Manuals:          https://github.com/shotgn16/Tolle/tree/main/docs/manual
