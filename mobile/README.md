# Tolle mobile apps (Android & iOS)

Capacitor shell around the Tolle web app in `../tolle/app/web`.

```bash
npm install
npm run add:android   # and/or npm run add:ios
npm run android       # or npm run ios
```

Full instructions, notifications, the optional Android "other Bible apps" tracker and the store publishing checklist: [../docs/mobile.md](../docs/mobile.md).
